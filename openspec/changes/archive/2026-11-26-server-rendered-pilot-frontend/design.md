# Дизайн серверного фронтенда

## Context

App Router используется для серверного рендеринга. Java API владеет правами, сессиями, переходами и данными. Учебный HTML обслуживается как самостоятельный статический файл.

## Goals / Non-Goals

Серверная загрузка рабочих страниц, типизированный контракт и воспроизводимый запуск.

## Decisions

- Серверные страницы загружают профиль, данные раздела и данные карточки посредством общего типизированного HTTP-клиента. Интерактивные формы, сообщения и обновления после действий работают в клиентских React-компонентах.
- Маршрут Next.js `/api/*` передаёт API-запросы по серверному `RISK_API_ORIGIN` и сохраняет повторяющиеся заголовки Set-Cookie. Персонализированные страницы и запросы к API обходят кэш. Cookie передаются только доверенному API. Spring Boot выполняет проверки сессии и CSRF.
- Транспорт описан в `api/openapi.yml`. Типы генерируются из контракта. В компонентных тестах HTTP-заглушка проверяет запросы и собственные ответы по соответствующей операции и статусу OpenAPI.
- Компонентный набор запускает Next.js с отдельной HTTP-заглушкой. E2E использует тот же интерфейс и настоящее приложение Spring Boot с отдельной PostgreSQL. Оба набора написаны на TypeScript.
- Compose собирает автономный Node.js-вывод Next.js, Java JAR и запускает PostgreSQL с именованным томом. Для HTTPS на командном стенде оператор подключает обратный прокси. Первый администратор создаётся отдельной командой.
