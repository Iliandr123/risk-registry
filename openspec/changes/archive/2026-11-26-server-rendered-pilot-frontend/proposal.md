# Серверный фронтенд пилота

## Why

Спецификация пилота почти не определяла устройство фронтенда, поэтому рабочий интерфейс загружал данные после запуска JavaScript в браузере. Нужны серверный рендеринг, простой запуск и два чётко определённых вида тестов.

## What Changes

- Серверные страницы Next.js на TypeScript, HTTP-клиент по OpenAPI и единый публичный адрес.
- Запуск Next.js, Spring Boot и PostgreSQL одной командой Docker Compose.
- Компонентные тесты с HTTP-заглушкой и E2E с работающими Java API и PostgreSQL.

## Capabilities

### New Capabilities

- `pilot-frontend` — серверный веб-интерфейс, запуск и критерии проверки.

### Modified Capabilities

## Impact

Фронтенд, сборка образов, локальный запуск, тесты и документация пилота.
