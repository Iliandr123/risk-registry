# Проверки прямого редактирования рисков

## MODIFIED Requirements

### Requirement: Два вида автоматических тестов

Автоматические тесты MUST ограничиваться компонентными проверками фронтенда с HTTP-заглушкой бэкенда и E2E с запущенным Spring Boot и отдельной PostgreSQL. Проверки типов, линтер, сборка и валидация схемы OpenAPI входят в технические проверки.

#### Scenario: Компонентный тест со сверкой контракта

- **WHEN** сценарий компонента выполняется с HTTP-заглушкой
- **THEN** проверяются серверный HTML или взаимодействие с реальным компонентом, операция OpenAPI, параметры, CSRF при записи, тело запроса, статус и схема ответа заглушки
- **AND** тест падает при неожиданном запросе или нарушении схемы

#### Scenario: Полный сценарий на реальном API

- **WHEN** E2E открывает рабочий интерфейс с запущенными Next.js, Spring Boot и PostgreSQL
- **THEN** через браузер проверяются роли, смена временного пароля, создание, возврат и утверждение, конфликт ревизий, видимость публикации, подтверждение оценки и архив с историей
- **AND** проверяются прямое сохранение по ролям, немедленная видимость правки для команды, история значений до и после, конфликт сохранения со старой версии и сохранность свежих полей при завершении
