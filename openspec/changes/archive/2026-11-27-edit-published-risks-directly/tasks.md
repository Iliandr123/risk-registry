# Задачи

## 1. HTTP-контракт

- [x] 1.1 Описать в `api/openapi.yml` прямое сохранение, поля и ошибки, изменения истории и ограничение предложений после публикации. Сгенерировать типы и проверить контракт командой `npm run api:check`.

## 2. Опубликованные поля и история

- [x] 2.1 Реализовать проверку роли, текущего назначения, состояния риска и версии под блокировкой. Записывать публикацию, дату оценки и событие атомарно. E2E проверяет права ответственного, ревьюера и администратора, отказ обычному участнику и бывшему ответственному, защиту неопубликованных и архивных рисков, проверки полей и конфликт двух сохранений.
- [x] 2.2 Добавить «Редактировать», обновление реестра и историю по полям. Сохранить ввод и показать свежие данные при конфликте. Компонентные тесты сверяют HTTP, CSRF, успешное сохранение, ошибки и сверку полей. E2E проверяет видимость для другого участника, несколько полей в одном событии, очистку и повторное сохранение тех же значений.
- [x] 2.3 Переиспользовать единый расчёт `reviewDueDate` и отметки о пересмотре. Проверить обновление даты при изменении оценки, сохранение даты при прочих правках, действующее правило конца месяца и явное подтверждение ревьюером.

## 3. Завершение и переход

- [x] 3.1 Вынести завершение в отдельную форму с текущими действиями согласования. E2E проверяет первую публикацию, согласование завершения, отказ в сохранении после архивирования и перенос последней опубликованной версии вместе с актуальным ответственным, группой и случаями проявления.
- [x] 3.2 Добавить миграцию обычных правок. Проверить на базе со старыми черновиками и отправленными или возвращёнными предложениями закрытие обычных правок, сохранение их содержимого и прежней видимости, а также возможность продолжить согласование завершения.
