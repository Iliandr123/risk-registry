# Проверка автономного прототипа

Открыть `../public/risk-register.prototype.html` двойным щелчком. Установка зависимостей и сервер не нужны. Все данные и заметки хранятся в памяти страницы и сбрасываются при обновлении.

Из `frontend/` запустить поведенческие проверки встроенным раннером Node.js (20.9+):

```sh
node --test tests/risk-register.prototype.test.cjs
```

Тесты извлекают чистую модель непосредственно из HTML, без копии логики и дополнительных пакетов. Проверяются переходы, права, видимость, сохранение опубликованных версий, завершение, оценки и календарные даты.

Для ручной проверки пройти шесть сценариев кнопками в верхней панели. Каждый сценарий восстанавливает исходные данные. Затем в свободном режиме проверить ввод, поиск, фильтры, переключение участников и раскрытие истории. При переключении участника несохранённые поля теряются: сначала сохранить черновик.

При проверке с командой записать затруднения в поле наблюдений и скопировать их перед закрытием. Оценка понятности настоящими участниками и совместный пилот остаются отдельным этапом.
