# Рабочий реестр рисков

Установите зависимости из `frontend/` с Node.js 20.9 или новее.

```sh
npm ci
npm run dev
```

Откройте [реестр](http://localhost:3000). Для входа нужен работающий API и учётная запись пилота. Настройка PostgreSQL и создание первого администратора описаны в [README бэкенда](../backend/README.md).

Запросы браузера к `/api` идут через Next.js на `http://127.0.0.1:8080`. Если порт или адрес бэкенда отличаются, задайте серверную переменную `RISK_API_ORIGIN` до запуска разработки или производственной сборки. Для командного стенда публикуйте интерфейс и API по одному HTTPS-адресу, чтобы браузер принимал защищённые cookies.

```sh
npm run lint
npm run typecheck
npm run build
```

Браузерные и контрактные проверки описаны в [руководстве по тестированию](tests/README.md). Автономный прототип можно открыть из `public/risk-register.prototype.html`.
