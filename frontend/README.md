# Frontend

Минимальный каркас Next.js 16, React, TypeScript, App Router и ESLint.
Главная страница пустая. Предметная логика и интеграция с backend отсутствуют.

Зависимости пока не установлены: окружение создания проекта блокирует доступ к npm.
После получения доступа к npm выполните из этой папки:

```sh
npm install
npm run dev
```

Установка создаст `package-lock.json`. Сохраните его в репозитории.
Фронтенд будет доступен по адресу http://localhost:3000.

Проверки после установки:

```sh
npm run lint
npm run typecheck
npm run build
```
